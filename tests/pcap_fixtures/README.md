# WiGuard PCAP Fixtures

This directory is for curated detector fixtures.

Synthetic fixtures under `synthetic/` are generated by WiGuard with Scapy and are safe to keep in Git. Raw captures from real RF environments should stay in `/tmp`, `.wiguard/`, or `data/raw/` unless they are deliberately sanitized and documented.

Regenerate the synthetic set:

```bash
wiguard-generate-fixtures tests/pcap_fixtures/synthetic
wiguard-evaluate-fixtures tests/pcap_fixtures/synthetic/manifest.json
```
